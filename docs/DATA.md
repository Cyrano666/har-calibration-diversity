# Data provenance and rights

Original sensor data belong to their respective providers. This release contains numerical model outputs, benchmark participant indices and derived evaluation artifacts. Subject indices are dataset identifiers, not named individuals. Raw USC-HAD recordings and third-party research PDFs are not distributed.

| Dataset | Provider |
|---|---|
| UCI HAR | https://doi.org/10.24432/C54S4K |
| DSADS | https://doi.org/10.24432/C5C59F |
| MHEALTH | https://doi.org/10.24432/C5TW22 |

| REALDISP | https://doi.org/10.24432/C5GP6D |
| USC-HAD | https://sipi.usc.edu/had/ |

The cited UCI dataset records describe their applicable licenses; dataset citations and provider terms continue to apply to derived data. USC-HAD should be obtained from its provider. Its supplied README is retained for provenance. One trial has conflicting filename and embedded activity metadata; the main locked analysis and a separate exclusion sensitivity are both documented.

Public repository visibility does not itself assign a new software or manuscript license. The research authors have not selected a separate code license. Third-party template files retain their existing notices and licenses. No license or ownership over third-party datasets is claimed by this project.
