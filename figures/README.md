# Figure sources

Figure1 is a native editable PowerPoint diagram; its PDF is exported from PowerPoint. L and U in that diagram denote the running lower and upper bounds, and D_t matches the stopping statistic in the manuscript. Panel labels identify fixed inputs, boundary calibration and the query loop.

Figures2 and3 are regenerated by visualization/replot_summary_bars.py from unchanged revision6/summaries/ tables. The current comparison uses plain vertical grouped bars with fixed method order and no per-bar numeric labels. The failure plot retains the threshold line and uses solid fills without dot or cross-hatch textures; exact values are reported in manuscript tables. All quantitative figures can be rebuilt with python visualization/rebuild_figures.py. The primary publication files are vector PDF/EPS with embedded fonts; PNG files are previews.

The HHAR primary conditions differ from the aggregate main-study plot. Its results remain separately reported in Table9; it is not appended as an apparently identical eighth dataset in Figure2.
