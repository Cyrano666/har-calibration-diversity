\title[Emulating conformal reference sets]{Label-efficient emulation of conformal reference sets for wearable activity recognition}
\abstract{Labeling a complete calibration pool can be expensive when a reference pool has been specified for a recognition system. We introduce joint rank calibration, a procedure that emulates this finite reference using sequential label queries. A coupled rank-state recursion calibrates the probability of crossing either quantile boundary at any declared query checkpoint. Acquisition stops when the endpoint prediction sets differ by at most a chosen average number of labels on an unlabeled monitoring batch. With high probability over uniform query order, the output contains the reference sets for every input and satisfies the batch-specific inflation tolerance. This conditional guarantee allows arbitrary dependence among fixed pool scores; it does not establish nominal population coverage for a deficient reference. The main study uses seven public wearable-activity datasets and 354 classifier cases, including a prospectively locked USC-HAD confirmation. With confidence error 0.05 and tolerance 0.5 extra labels, confirmation label savings are 23.67\%, compared with 17.91\% for Bonferroni hypergeometric intervals and 11.74\% for a uniform-prior confidence sequence. A subsequent stronger-prior audit raises the latter baseline to 15.33\%, while the proposed result remains unchanged. Savings vary substantially across datasets, including limited gains on difficult recognition problems. A separately specified nine-user confirmation adds 45 classifier cases and yields 34.03\% savings versus 25.13\% for the stronger-prior baseline.}
\keywords{Human activity recognition, Conformal prediction, Label acquisition, Finite-population inference, Sequential calibration}

\section{Introduction}
Wearable human activity recognition (HAR) often transfers a trained classifier to people whose movements differ from the training cohort. Its probability scores may be poorly calibrated under this shift \cite{guo,ovadia}. Prediction sets expose uncertainty by retaining several candidate activities, but constructing them requires labeled calibration examples. For wearable data, these examples frequently comprise repeated windows from a small number of people. The cost of labeling a pool and the reliability of predictions on new people are therefore separate design questions.

Conformal prediction converts a nonconformity score into a prediction set with statistical guarantees under specified sampling assumptions \cite{vovk,angelopoulos}. Subject-disjoint partitions prevent person leakage; they do not, by themselves, establish exchangeability under arbitrary subject shift. Hierarchical and beyond-exchangeability methods address this distinction through additional structure or assumptions \cite{dunn,barber}. Consequently, a historical estimate that a smaller calibration set has acceptable risk may not transfer to a new cohort.

This study targets the labeling cost of preserving a fixed calibration reference. Suppose a finite pool of sensor windows has already been chosen for calibration. Labeling the entire pool defines a reference quantile and its prediction sets. We ask when label acquisition can stop earlier while retaining those sets and limiting the additional candidate labels on a specified batch of inputs. The reference may itself be imperfect; the acquisition procedure protects its predictions without asserting a new population-coverage guarantee.

Uniformly random label-query order permits design-based inference about the reference quantile, conditional on arbitrarily dependent finite score values. We introduce joint rank calibration (JRC), which tracks the number of queried ranks below the reference and whether the reference item itself has appeared. A finite-state recursion evaluates the joint probability of crossing either quantile boundary at any declared checkpoint. Calibrating this probability uses the available error budget more directly than assigning a separate tail allowance to every look. The output threshold is the upper confidence endpoint, and the stopping condition measures the difference in prediction-set membership between the two endpoints on unlabeled monitoring inputs.

Adaptive calibration stopping and the use of unlabeled set-size estimates are already established. Ilyas et al. \cite{ilyas} optimize a joint labeling-and-ambiguity cost under i.i.d. sampling; confidence-sequence methods permit valid optional stopping more generally \cite{howard2021,howard2022,wor}. JRC specializes these ideas to a different statistical contract: containment of a predetermined finite reference for every input, together with bounded average set inflation on a declared monitoring batch. Its contribution is the coupled rank-path calculation and the resulting finite-reference acquisition procedure.

We evaluate this procedure on seven public activity datasets using logistic regression (LR), MiniRocket (MR) and a fixed InceptionTime-style classifier (IT). Six datasets support development and reanalysis; USC-HAD provides a separately locked confirmation. A subsequently specified cohort tests the unchanged method in an additional 45 classifier cases. Comparisons include two quantile-interval methods, fixed labeling fractions and mechanism ablations. Additional checks examine stronger prior choices in the confidence-sequence baseline and an ambiguous original dataset label. The analysis reports both useful savings and cases requiring nearly all reference labels, separating computational correctness, reference utility and acquisition efficiency.

\section{Related work}
\subsection{Wearable recognition and uncertainty}
Recent activity-recognition methods improve the representation or adaptation stage. STF-AL combines temporal, spatial and frequency representations with adversarial domain adaptation \cite{stfal}. CCT-HAR introduces cross-modal sample mining and temporal alignment \cite{ccthar}; TSDFSA studies attention-based feature selection for multiple sensors \cite{tsdfsa}. Their ablations and controlled evaluations motivate testing whether an acquisition gain survives simple competing rules. Their published recognition accuracies are not numerical baselines for JRC because their sensor inputs, training interventions and data access differ.

Uncertainty estimation in HAR also predates this study. Roy et al. examine confidence-calibrated activity recognition \cite{roy}, and hyperdimensional/conformal approaches address uncertainty on microcontrollers \cite{hduq}. We use established MiniRocket \cite{minirocket} and InceptionTime \cite{inception} model families to test sensitivity to the underlying score distribution. The recognition models remain fixed across acquisition policies.

\subsection{Label-efficient stopping and its statistical target}
Ilyas et al. \cite{ilyas} study a stream of $n$ i.i.d. examples and the cost
\begin{equation}
 C(m)=m+(n-m)\,\mathbb E[|T_m(X)|]/K.
 \label{eq:relatedcost}
\end{equation}
Their submitted manuscript uses a time-uniform conformal threshold and estimates normalized set size from all candidate-label scores on unlabeled inputs. The theoretical stopping rule detects a nonnegative lower bound on an oracle cost increment and uses a monotone score-density-ratio assumption in its regret analysis. Section 7 also describes a finite-sample stabilization used in the experiments. Set-size-based stopping and invariance of rank/set operations to increasing score transformations are shared ingredients.

The statistical targets differ. The i.i.d. procedure seeks high-probability population coverage and cost optimality relative to fixed calibration sizes. JRC conditions on one finite reference pool and seeks high-probability inclusion of that pool's reference sets, with bounded additional set size on a separate declared batch. Table~\ref{tab:related} summarizes these contracts. Percentages reported for ImageNet total cost in the submitted Ilyas manuscript cannot be compared directly with our percentages of saved reference labels. The comparison uses its original-submission version and distinguishes the theoretical rule from its stabilized experimental implementation.

Training-conditional validity has a longer history \cite{vovk2012}. Liang et al. \cite{liangstop} study conformal inference with early stopping of neural-network training and reuse of hold-out data; JRC operates after classifier fitting is complete. Xu et al. \cite{active2024} develop active, anytime-valid risk-controlling sets with a labeling policy and risk-predictor assistance. The August 2026 preprint by Skalse et al., \emph{Online Conformal Prediction Beyond Feedback} (arXiv:2608.07139v1), studies a prediction/query game on non-i.i.d. streams. These population-risk and online-game targets differ from protecting a predetermined finite reference, although all address limited labeling resources.

\subsection{Sequential finite-population inference}
Finite-population sampling and hypergeometric inversion are standard statistical tools \cite{cochran}. Time-uniform confidence sequences \cite{howard2021}, sequential quantile estimation \cite{howard2022}, sampling-without-replacement confidence sequences \cite{wor}, and exact hypergeometric group-sequential tests \cite{jin} supply the closest foundations. The corrected conformal quantile and cumulative-probability scores are likewise established \cite{angelopoulos,romano}. JRC contributes a specialized joint rank-state calculation for a known finite horizon and reference rank. The experiments isolate the benefit of this calculation by applying the same reference pool, query order and set-inflation tolerance to established interval methods.

\subsection{Target, information and cost}
Let a trained classifier be fixed before calibration acquisition. For a nonconformity score $s(x,y)$, its thresholded prediction set is
\begin{equation}
 C(x;q)=\{y\in\mathcal Y:s(x,y)\le q\}.
 \label{eq:sets}
\end{equation}
The label set $\mathcal Y$ is finite, with $K$ classes. We fix a reference pool $\mathcal P=\{x_i\}_{i=1}^N$ before requesting its labels. The unknown true-label scores $S_i=s(x_i,y_i)$ are regarded as fixed values. Define
\begin{equation}
 k=\lceil(N+1)(1-\alpha)\rceil,\qquad
 q_{\rm ref}=S_{(k)},
 \label{eq:reference}
\end{equation}
with $q_{\rm ref}=+\infty$ if $k>N$. The full-pool reference predictor is $C(x;q_{\rm ref})$. Our target is to emulate this predictor with fewer queried labels. The reference rank uses the familiar split-conformal correction, but dependence within a pool does not make the resulting predictor marginally valid. Reference containment and population coverage are different statements.

We condition on all pool values, the trained classifier and a batch $\mathcal X_\star$ of $M$ unlabeled monitoring inputs. The only randomization in the guarantee is a uniform permutation of the $N$ pool indices, chosen independently of their unrevealed labels. Labels are revealed in this order. Correlation between people, repeated windows and trials can be arbitrary because the argument concerns sampling from a fixed population. A label-driven query ranking or replacing the pool after inspecting its labels would not satisfy this design.

All class scores on $\mathcal X_\star$ are available without its true labels. They determine when a quantile interval is sufficiently precise for prediction-set utility. Using held-out inputs this way is a transductive protocol. Its set-size statement applies to this finite batch; it is not a guarantee of size control on a different deployment distribution. The containment statement below holds for every input on the confidence event.

The primary cost is the number $T$ of queried window labels. When the pool involves $m$ participants and each has setup cost $c$, a conservative secondary effort model is $T+cm$, against the reference cost $N+cm$. Every participant's setup is charged to both policies, even if stopping occurs before that participant's first queried window. These are modeled effort units. Presegmentation, obtaining sensor recordings and constructing the reference pool are outside the label-query savings.


\begin{algorithm*}[t]
\caption{Joint rank calibration for a fixed reference pool}\label{alg:jrc}
\begin{algorithmic}[1]
\Require Frozen score function; fixed pool of $N$ windows; uniform query permutation; monitoring scores; $\alpha,\delta,\tau$; checkpoints $\mathcal T$
\State Set $k=\lceil(N+1)(1-\alpha)\rceil$ and calibrate rank boundaries $(\ell_t,u_t)$ by the joint recursion
\Statex \hspace{\algorithmicindent}\textit{Joint recursion: Section~\ref{sec:joint}, Eqs.~\eqref{eq:transition}--\eqref{eq:crossing}.}
\State Initialize observed scores $\mathcal S\gets\varnothing$, $L\gets-\infty$, $U\gets+\infty$
\For{each checkpoint $t\in\mathcal T$}
\State Query only the new labels needed to reach $t$ observations and add their true-label scores to $\mathcal S$
\State Obtain the current rank bracket $(L_t,U_t)$ from the ordered observed scores
\State Form $(L',U')\gets(\max\{L,L_t\},\min\{U,U_t\})$
\If{$L'>U'$}
\State Record an empty-intersection event and use $(L',U')\gets(L_t,U_t)$
\EndIf
\State Set $(L,U)\gets(L',U')$ and calculate $D_t$ from the monitoring scores using Eq.~\eqref{eq:width}
\If{$D_t\le\tau$}
\State \Return queried count $t$ and predictor $C(x;U)$
\EndIf
\EndFor
\end{algorithmic}
\end{algorithm*}

\subsection{Finite-population rank brackets}
Choose checkpoints $\mathcal T\subseteq\{1,\ldots,N\}$ with $N\in\mathcal T$. If scores tie, order the complete population by the pair $(S_i,i)$, using the fixed pool index to break ties. The numerical inequalities below remain valid when these pairs are projected onto their score values.

Let $J_t$ count the queried items whose full-population ranks are strictly below $k$, and let $R_t$ indicate whether the item of rank $k$ has appeared. Then $J_t+R_t$ counts sampled items with rank at most $k$. Their separate marginal distributions are
\begin{equation}
 \begin{aligned}
 J_t&\sim\operatorname{Hypergeom}(N,k-1,t),\\
 J_t+R_t&\sim\operatorname{Hypergeom}(N,k,t).
 \end{aligned}
 \label{eq:hg}
\end{equation}
Write $Q_p(N,a,t)$ for the smallest integer whose hypergeometric cumulative probability is at least $p$. At a common tail parameter $\eta$, use sample-rank boundaries
\begin{equation}
 \ell_t=Q_\eta(N,k,t),\quad
 u_t=Q_{1-\eta}(N,k-1,t)+1.
 \label{eq:ranks}
\end{equation}
For the ordered observed scores $S^{[t]}_{(j)}$, set
\begin{equation}
 L_t=S_{(\ell_t)}^{[t]},\qquad U_t=S_{(u_t)}^{[t]}.
 \label{eq:bracket}
\end{equation}
Here $\ell_t$ is the lower sample-rank index defined in Eq.~\eqref{eq:ranks}. The conventions are $S^{[t]}_{(0)}=-\infty$ and $S^{[t]}_{(t+1)}=+\infty$. At the census, both bounds are the known $S_{(k)}$. When $k>N$, both are $+\infty$ and the reference already contains every label.

On a path satisfying $J_t+R_t\ge\ell_t$ and $J_t<u_t$, at least $\ell_t$ observations have full rank at most $k$, while fewer than $u_t$ observations have rank below $k$. Consequently, $L_t\le q_{\rm ref}\le U_t$. A standard simultaneous-coverage construction uses $\eta=\delta/[2(|\mathcal T|-1)]$ and a union bound over the non-census checkpoints. The resulting Bonferroni hypergeometric (HG) brackets form the first baseline.

\subsection{Joint calibration of the checkpoint boundaries}\label{sec:joint}
The union bound does not use the strong dependence between nearby checkpoints or between the two rank-count processes. We instead compute their joint crossing probability. Conditional on state $(J_t,R_t)=(j,r)$, the next observation has rank below $k$, equal to $k$, or above $k$, with probabilities
\begin{equation}
 \frac{k-1-j}{N-t},\qquad
 \frac{1-r}{N-t},\qquad
 \frac{N-k-t+j+r}{N-t},
 \label{eq:transition}
\end{equation}
respectively. They lead to states $(j+1,r)$, $(j,1)$ and $(j,r)$. Impossible transitions have probability zero. Start with mass one at $(0,0)$; propagate these probabilities and absorb mass at any checkpoint for which
\begin{equation}
 j+r<\ell_t\quad\text{or}\quad j\ge u_t.
 \label{eq:crossing}
\end{equation}
The absorbed mass $A(\eta)$ is the exact probability of at least one rank-boundary crossing under the finite query design. There are at most $2k$ states at each time. Direct propagation costs $O(Nk)$ operations and $O(k)$ working memory for a specified boundary family. It is performed before label queries and reused across pools with the same $N$, $k$, confidence level and checkpoints.

Increasing $\eta$ weakens both tail protections, so $A(\eta)$ is nondecreasing, although discrete. We search this one-dimensional family by 24 bisection steps and retain a feasible value satisfying $A(\eta)\le\delta-10^{-10}$. The small numerical slack is implementation protection; the statistical claim concerns the exact recursion. Exact group-sequential calibration is established \cite{jin}; the contribution here is the coupled rank-state construction for preserving a finite calibration reference, together with the prediction-set stopping target.

\subsection{Stopping in prediction-set space}
Intersect valid past brackets by setting $\overline L_t=\max_{v\le t}L_v$ and $\overline U_t=\min_{v\le t}U_v$, where $v\in\mathcal T$. On the simultaneous coverage event this intersection contains $q_{\rm ref}$. An empty intersection signals that event has failed; the implementation records it and falls back to the current bracket. At the census it returns the exact quantile regardless of previous events.

The stopping statistic is observable without monitoring labels:
\begin{equation}
 D_t=\frac1M\sum_{x\in\mathcal X_\star}
 \bigl[|C(x;\overline U_t)|-|C(x;\overline L_t)|\bigr].
 \label{eq:width}
\end{equation}
For a prespecified tolerance $\tau\ge0$, stop at the first checkpoint with $D_t\le\tau$ and return $C(x;\overline U_T)$. The census guarantees termination. The quantity $\tau$ is an absolute number of additional labels per input, not a normalized score width or coverage margin. An arbitrary numerical score tolerance would change meaning under a monotone reparameterization of the nonconformity score; this stopping statistic depends on actual prediction-set memberships.

\textbf{Proposition 1 (reference preservation).}
For a fixed classifier, finite reference pool, monitoring batch and declared checkpoints, suppose the joint recursion yields $A(\eta)\le\delta$. Under uniform sampling without replacement, with probability at least $1-\delta$, the returned predictor satisfies simultaneously
\begin{equation}
 C(x;q_{\rm ref})\subseteq C(x;\overline U_T),
 \label{eq:containment}
\end{equation}
for every input $x$, and
\begin{equation}
 \frac1M\sum_{x\in\mathcal X_\star}
 \bigl[|C(x;\overline U_T)|-|C(x;q_{\rm ref})|\bigr]
 \le\tau.
 \label{eq:inflation}
\end{equation}
No independence assumption on the fixed score values is required.

\textit{Proof.} The recursion enumerates the law of the uniformly sampled rank path. Except on an event of probability $A(\eta)$, neither inequality in Eq.~\eqref{eq:crossing} holds at any checkpoint. The rank argument above gives $L_t\le q_{\rm ref}\le U_t$ simultaneously. Running intersections therefore contain $q_{\rm ref}$ and are nonempty. Since the sets in Eq.~\eqref{eq:sets} are nested in $q$, the upper endpoint gives Eq.~\eqref{eq:containment} for every input. The reference set lies between the sets at the lower and upper endpoints, so its extra-label difference is bounded pointwise by the summand in Eq.~\eqref{eq:width}. At the data-dependent stopping time, the average is at most $\tau$. The confidence event covers every checkpoint and hence also this stopping time.\hfill$\square$

Containment implies that empirical coverage cannot decrease for any fixed labeled test collection on this event; each individual's positive coverage shortfall also cannot increase. It does not repair a poorly calibrated reference. The failure probability $\delta$ is attached to one label-query run. It is not automatically a familywise guarantee for thousands of experiment configurations or repeated future deployments.

Strictly increasing score transformations preserve the rank ordering and every thresholded set membership, so they leave the query count and returned sets unchanged. This standard property of rank/set-based procedures is used as an implementation check.

\subsection{Implementation and comparison methods}
Sorted monitoring scores allow Eq.~\eqref{eq:width} to be computed using two binary searches. Each checkpoint sorts the observed label scores. This direct implementation is adequate for the pool sizes studied; dynamic order-statistic structures could reduce repeated sorting for larger pools. Precomputed boundary tables are separate from per-pool query execution.

Both quantile-interval baselines satisfy the same finite-pool confidence constraint as JRC: conditional on the complete fixed pool, their intervals contain $q_{\rm ref}$ simultaneously at all declared checkpoints with probability at least $1-\delta$ over uniform sampling without replacement. The comparison uses the same upper-endpoint output and set-inflation stopping rule. Population coverage remains a separate property of the reference predictor.

The second quantile-interval baseline inverts the prior/posterior-ratio confidence sequence (CS) of Waudby-Smith and Ramdas \cite{wor}. A uniform prior on the number of successes in the population induces the ordered-prefix mixture likelihood $B(j+1,t-j+1)$. For a hypothesized population count $a$, divide this mixture likelihood by
\begin{equation}
 \mathcal L_t(a,j)=
 \frac{(a)_j\,(N-a)_{t-j}}{(N)_t},
 \label{eq:likelihood}
\end{equation}
where $(a)_j$ denotes a falling factorial. Invert the resulting e-process separately at counts $k$ and $k-1$, allotting each error $\delta/2$. The minimum accepted count at $k$ gives the lower sample rank; one plus the maximum accepted count at $k-1$ gives the upper rank. We use the same running intersection, checkpoints and prediction-set stopping tolerance as the proposed engine. This is an implementation of an established confidence-sequence principle, not a separate new method.

We additionally compare ordinary conformal quantiles from fixed 25\%, 50\% and 75\% prefixes, and an upper hypergeometric bound at a single fixed 50\% look. The former have no reference-containment guarantee. The latter protects the reference at that fixed look but does not adapt label expenditure to a prescribed set-size tolerance. Diagnostic ablations omit time correction, omit running intersection, return a midpoint at the proposed stopping time, or use sparse checkpoints. Their different guarantees are kept explicit.
\section{Experimental design}
\label{sec:experiments}
\subsection{Data and development history}
The six development/reanalysis datasets are UCI HAR \cite{har}, DSADS \cite{dsads}, MHEALTH \cite{mhealth}, WISDM \cite{wisdm}, PAMAP2 \cite{pamap} and REALDISP \cite{realdisp}. They contain 122 eligible subject identifiers and 54,482 retained windows. These benchmarks were examined during earlier acquisition-policy development, including unsuccessful historical-risk and randomized-allocation candidates. In particular, PAMAP2 and REALDISP were confirmation datasets for an earlier locked rule, whose frequent tolerance-transfer failures motivated the present change of target. They are not described as independent confirmation of the current method. Online Resource 1 preserves the earlier protocol and its aggregate negative results.

USC-HAD \cite{uschad} is the additional prospective confirmation benchmark. The method, confidence level, primary tolerance, query schedule, preprocessing and splits were locally locked on 12 September 2026 before any of its model predictions were available. This is a timestamped local lock, not an externally preregistered study. All 14 participants meet the requirement of at least 120 retained windows. The resulting confirmation array contains 5,353 windows and 12 classes. The complete seven-dataset evaluation therefore uses 136 subject identifiers and 59,835 windows. Totals refer to dataset-specific participant identifiers.

The selected input is three acceleration axes resampled to 128 time points. UCI HAR uses the release's 2.56-second total-acceleration windows, retaining alternating windows per subject; its release ordering is not verified raw chronology. DSADS uses five-second torso-acceleration segments. MHEALTH uses five-second chest windows; WISDM uses five-second smartphone-acceleration windows from its 18-activity release. PAMAP2 uses protocol chest acceleration, and REALDISP uses ideal-placement BACK acceleration. The original REALDISP manual places BACK third in the log, unlike the fifth position listed in the repository webpage summary; we follow the original manual. The retained sample counts and preprocessing provenance are included in Table~\ref{tab:data} and the supplement. Different window durations in the original HAR release prevent interpreting the seven datasets as identical sensor protocols.

For USC-HAD, each original MAT trial remains separate. We take nonoverlapping 500-sample windows at the documented 100 Hz, retain acceleration columns 1--3, reject nonfinite windows and incomplete tails, and use anti-aliased polyphase resampling to 128 points. Dataset-provided trial segmentation is treated as available; our label-cost model does not charge or solve raw-stream segmentation. The filename convention supplies activity IDs. An independent schema audit finds one conflict: Subject14/a3t2.mat is activity 3 by filename but activity 2 (walking-left) in its internal metadata. Main labels follow the locked filename rule. A separate sensitivity excludes that trial, refitting classifiers whenever it occurs in training. Another file lacks the optional numeric activity field but has a matching activity-name string; it is retained. No exact duplicate signal arrays are found among the 840 trials. These qualifications are reported rather than silently correcting uncertain labels.

\subsection{Frozen classifiers and subject partitions}
Every acquisition method uses identical probability vectors within a classifier case. Logistic regression (LR) uses 35 standardized statistical features, regularization $C=1$ and a maximum of 2,000 iterations. MiniRocket (MR) uses 2,016 kernels followed by a standardized logistic-regression head. The InceptionTime-style model (IT) uses six modules, 32 filters per branch, kernel lengths 39, 19 and 9, residual connections every third module, global pooling and a classification head. It is trained for 40 epochs with Adam, learning rate $10^{-3}$ and batches of 128, without a test-selected checkpoint. The statistical features, normalization and model code are shared with the preceding frozen model study. Scikit-learn and SciPy support the classical pipeline \cite{sklearn,scipy}.

We reuse 249 cases from 83 outer partitions on the six development datasets. Each case has disjoint training, calibration and test participants. The earlier study trained auxiliary out-of-fold models, but this method does not require their predictions or their fit cost. USC-HAD has five fixed random seeds and seven test folds per seed: two test participants, eight training participants and four calibration participants in each fold. This gives 35 partitions and 105 new final-classifier fits. The 354 model cases reuse the 83 development and 35 confirmation partitions; repeated results are aggregated within participants.

The least ambiguous set-valued classifier (LAC) score \cite{sadinle} is $s(x,y)=1-\widehat p_y(x)$. The secondary score uses adaptive prediction sets (APS) \cite{romano} in a deterministic inclusive form: sort class probabilities in descending order, with stable class-index ties, and assign each class its cumulative probability. There is no randomization within the APS score and no forced top-label insertion. Empty and full sets remain in the calculations. The same scoring convention is used for the reference and every acquisition comparator, and $\alpha=0.1$ throughout.

\subsection{Reference pools and query experiments}
For a requested pool ceiling $B\in\{120,240,480,960\}$ and $m$ available calibration participants, the actual pool size is $N=\min(B,120m)$. All participants contribute quotas that differ by at most one; a random participant ordering assigns any remainder. We sample each participant's quota uniformly without using its labels, then independently randomize the order of the selected pool. Some ceilings thus produce the same actual pool size; we retain all declared ceilings and disclose this saturation rather than treating the requested ceiling as the number of labels acquired.

The primary parameters are confidence error $\delta=0.05$, additional-label tolerance $\tau=0.5$ and checkpoints every 20 queried labels plus the census. A tolerance of 0.5 limits the mean increase in candidate labels on the monitoring batch; it is neither a 0.5\% coverage margin nor a cap of one extra label for every individual input. The secondary tolerances are 0.1, 0.25 and 1.0, reported together. Forty paired pool/query randomizations per case and ceiling reduce Monte Carlo variability. Seeds, participants and windows are shared by the comparator evaluations. Simulators retain full labels to calculate the reference, but decisions use only prefixes; a separate oracle-based implementation verifies that execution stops without requesting any later label.

The complete test-input batch supplies the monitoring scores, with labels hidden. The principal size measure used by the stopping rule is window-weighted on that batch. Subject-level empirical coverage and size are also reported with equal weight per subject. These two weightings are deliberately distinguished: a finite-batch guarantee on the former is not automatically an individual-subject size bound. The universal containment event does protect every subject's reference coverage simultaneously.

\subsection{Metrics, uncertainty and ablations}
Primary outcomes are queried-label savings $1-T/N$, reference-set containment failure and batch size inflation. We report each outcome without combining them into a favorable aggregate score. A containment failure is the conservative scalar event $\overline U_T<q_{\rm ref}$; with ties or gaps in candidate scores, this can flag a threshold failure even when no observed test set loses a label. Bracket failure checks both endpoints. Size failure checks whether actual mean extra labels on the monitoring batch exceed $\tau$. Each query campaign is counted once, regardless of the number of held-out people.

For a test participant with empirical coverage $c_u$, positive shortfall is $(0.9-c_u)_+$. The positive part is calculated before averaging randomizations. Accuracy and macro-F1 describe the frozen point classifiers; they are not objectives optimized by acquisition. Subject means average over paired randomizations and repeated partitions before aggregation. We compute paired 95\% bootstrap intervals by resampling participant summaries within a dataset, conditional on the fixed model runs. These intervals describe participant heterogeneity in this benchmark; shared training sets and few dataset domains limit broader inferential claims. We do not treat repeated windows, query draws or model fits as additional independent people.

JRC, Bonferroni HG and the prior/posterior confidence sequence use identical tolerances and query checkpoints. Ablations remove the running intersection, use a sparse checkpoint grid, omit repeated-look correction, or substitute a midpoint output at the proposed stopping time. The latter two lack the stated guarantee. Fixed fractions and a one-look upper bound are reported as additional cost/utility operating points, not as methods that satisfy the same stopping contract. Exploratory sensitivities vary $\delta$ and monitor on even-indexed inputs while evaluating size on odd-indexed inputs in the first MR case of each development dataset. The latter probes a limitation of the batch-specific statement and is not used to extend it to unseen distributions.

All runs use an Intel Core i9-12900HX CPU and an RTX 4070 Laptop GPU with 8 GB memory for neural training. We measure boundary-table construction separately from online acquisition calculations. Neither these timings nor modeled participant setup costs are measurements of wearable-device energy or human annotation duration. Exhaustive small-population enumeration checks both rank engines and the coupled recursion; additional checks cover ties, census behavior, oracle access and strictly monotone score transformations.



\subsection{Additional HHAR confirmation}
After the main seven-dataset study, an additional Heterogeneity Human Activity Recognition (HHAR) confirmation \cite{hhar} was specified and publicly committed on 14 September 2026 before preprocessing outcomes or model fitting. The frozen method and classifier implementations were retained. All smartphone-accelerometer streams were processed separately by user and device. Five-second nonoverlapping windows were formed within activity-consistent runs, splitting at non-increasing timestamps or gaps above 0.5~s. Windows required at least 60 finite samples and 4.9~s of observed duration. Timestamp interpolation at 200~Hz followed by anti-aliased resampling produced 128 points. A label-blind random cap of 1,200 windows per user retained 10,800 windows from nine users and six classes. The fixed continuity filter retained very few Nexus4 windows; Online Resource~1 reports device-specific retention, so the result does not represent uniform validation across all original device streams.

Five declared seeds and three user-disjoint test folds used four training, two calibration and three test users per fold, yielding 45 additional LR/MR/IT cases. The primary analysis used LAC, $N=240$, $\delta=0.05$, $\tau=0.5$ and 40 paired query orders; $N=120$ and APS were secondary. Alongside Bonferroni HG, the fixed Beta$(9,1)$ confidence-sequence prior was a primary comparator, chosen from the preceding diagnostic before HHAR outcomes. User-level paired differences and 95\% bootstrap intervals follow the declared aggregation. This cohort is reported separately from the main USC-HAD confirmation.

\subsection{Sensitivity to stronger confidence-sequence priors}
The primary confidence-sequence baseline uses a uniform prior on the finite-population success count. After reviewing the nearest label-efficient stopping literature, we tested four fixed beta-binomial prior choices across all 354 existing classifier cases. A Beta$(a,b)$ mixture replaces the ordered-prefix mixture likelihood by $B(j+a,t-j+b)/B(a,b)$ while retaining the same likelihood-ratio construction and error allocation. Exact rank-path checks verify the error bound for each finite design used. The diagnostic reuses the main models and queries after confirmation; the locked JRC rule is unchanged.

Table~\ref{tab:priors} reports all four prior choices. Tail-centered priors improve the baseline, showing that the uniform-prior comparison alone understates the performance of this method family. On USC-HAD, the strongest of the tested alternatives saves 15.33\% of labels, compared with 11.74\% for the primary uniform prior and 23.67\% for JRC. JRC retains the largest dataset-average savings among these choices on all seven datasets. The comparison covers the four specified priors and the declared benchmark designs. Reconstructing JRC and the uniform-prior results reproduces the frozen dataset averages within $10^{-12}$.

\section{Discussion and limitations}
Joint rank calibration reduces the conservatism caused by protecting each query checkpoint separately. Its empirical benefit is largest when the reference quantile can be localized without adding many candidate labels. The stronger-prior diagnostic shows that part of the original gap to the confidence-sequence baseline can be recovered by changing its prior; JRC retains an advantage across the tested dataset averages. The resulting method connects a calibrated finite-pool error budget to an interpretable set-inflation tolerance.

The practical interpretation depends on the reference and the annotation workflow. Broad or poorly calibrated reference sets remain a limitation even if their inclusion is certified. Uniformly scattered label queries may also cost more to annotate than contiguous records. The model $T+cm$ accounts for participant setup but does not measure annotation duration, context switches or segmentation effort. Adapting the rank law to clustered or nonuniform queries would be needed to cover these workflows.

The containment event protects every input's reference set, whereas the size-inflation tolerance is an average over one declared, unlabeled monitoring batch. It does not impose an individual-subject or future-batch size bound. The confidence-level and even/odd monitoring sensitivities in Online Resource 1 probe these limits without changing the main stopping rule.

The main benchmark spans seven datasets, with USC-HAD reserved before its predictive results were inspected. HHAR supplies a separately specified additional confirmation. The earlier stronger-prior and ambiguous-label checks are subsequent diagnostics. Repeated fits and query draws characterize this benchmark; they do not substitute for additional independent deployment domains. Practical annotation studies and additional deployment conditions would strengthen the application evidence.

\section{Conclusion}
Finite-pool reference emulation offers a concrete target for reducing calibration-label acquisition under dependent wearable measurements. Joint calibration of the sampled rank path yields confidence brackets that support a label-free stopping decision based on actual prediction-set changes. On the confidence event, the output preserves every reference set and respects the allowed average ambiguity on the monitoring batch. The seven-dataset experiment compares this specialization with established interval methods and simple cost cuts, while retaining weak-reference and low-savings cases. These findings support using JRC with a fixed reference pool and the declared query design, while identifying conditions in which little label reduction can be expected.
