# Additional HHAR confirmation

The protocol is specified before preprocessing outcomes, model fitting and predictive-result inspection. HHAR is an independently collected public cohort that was not part of the previous seven-dataset model study. This study keeps the original JRC method fixed and explicitly includes the stronger Beta(9,1) confidence-sequence comparator.

The intended design uses nine users, five seeds, three disjoint-user test folds and the unchanged LR/MR/IT models, for 45 fitted cases. Primary evaluation is LAC, confidence error 0.05, tolerance 0.5 and a 240-window reference pool. Results will be reported whether favorable or not.

See protocol.json and protocol_lock.json for the original settings and timestamp. This is a public, timestamped project protocol, not registration with an independent trial registry. Data-provider metadata were consulted before specifying the protocol; no HHAR predictions were available at that time.

This experiment concerns saved calibration labels, not measured human annotation time. Dataset source and license: https://archive.ics.uci.edu/dataset/344/hhar (CC BY 4.0).
